Guia de Configuração

Gmail API

  1. Acesse Google Cloud Console
  2. Crie um projeto e ative a Gmail API
  3. Vá em Credenciais > Criar ID do cliente OAuth
  4. Tipo: Aplicativo Web, URIs: http://localhost:3000
  5. Copie o Client ID e substitua no arquivo js/config.js

CLIENT_ID: COLE_AQUI_SEU_CLIENT_ID

Outlook API (Microsoft Graph)

  1. Acesse Azure Portal
  2. Vá em Microsoft Entra ID > Registros de aplicativos
  3. Crie um novo registro, URIs: http://localhost:3000
  4. Adicione permissões: Mail.Send, Mail.Read
  5. Copie o Client ID e Tenant ID

CLIENT_ID: COLE_AQUI_SEU_CLIENT_ID

TENANT_ID: COLE_AQUI_SEU_TENANT_ID
